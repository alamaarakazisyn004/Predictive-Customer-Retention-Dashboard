# Predictive Customer Retention Dashboard

##  Overview
This project uses machine learning and Tableau to identify customers at high risk of churn and provide actionable retention insights.

##  Objective
- Predict churn probability
- Segment customers into risk levels
- Identify Top 100 high-risk customers

##  Tools Used
- Python (Random Forest Model)
- Tableau (Dashboard Visualization)

##  Key Features
- KPI Metrics (Churn Rate, High Risk Customers)
- Risk Distribution Analysis
- Churn by Geography
- Age vs Churn Probability
- Top 100 Customers Table

##  Outcome
The dashboard helps businesses take proactive retention actions by focusing on customers with the highest churn risk.
